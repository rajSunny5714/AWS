## 🌩️ What is AWS?

**Amazon Web Services (AWS)** is a cloud computing platform provided by **Amazon**.

It provides on-demand cloud services for:

- 🖥️ Computing
- 🪣 Storage
- 🗄️ Databases
- 🌐 Networking
- 🔐 Security
- 📊 Monitoring
- 🤖 AI & Machine Learning
- 🔄 DevOps

AWS allows organizations to build, deploy, and scale applications without maintaining physical infrastructure.

## 🧩 Major AWS Services

### 🖥️ Compute

#### ⚡ Amazon EC2

**Elastic Compute Cloud (EC2)** provides virtual servers in the cloud.

**Used for:**
- 🌐 Web applications
- 🔌 Backend APIs
- 🖥️ Application servers
- ⚙️ Custom workloads
